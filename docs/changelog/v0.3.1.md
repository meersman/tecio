## [0.3.1]

Robustness improvementes.

### Changed

- Enums (`ZoneType`, `DataType`, `FileType`, `ValueLocation`, `DataPacking`,
  `FileFormat`, `FeCellShape`, `FaceNeighborMode`, `VarStatus`, `Boolean`,
  `Debug`) now live in `tecio._constants` and are importable directly from the
  top-level `tecio` package (`tecio.ZoneType`, not just
  `tecio.libtecio.ZoneType`), matching every other public class. Still
  re-exported from `tecio.libtecio` for backward compatibility.
- `tecio.libtecio`'s C-library load/bind mechanism is now implemented as
  reusable, stateless functions in `tecio._utils` (`load_library`, `bind`,
  `requires_symbol`); `libtecio.py` itself is reduced to the C function
  wrappers and their own state (`lib`, `LIBRARY_LOAD_ERROR`, `LIBRARY_PATH`,
  `UNAVAILABLE_FUNCTIONS`). No behavior change; importing `tecio.libtecio`
  still never raises, even with no Tecplot installation or an older one
  missing a newer symbol.
- `bind` is now keyword-only at its call sites for readability.

### Fixed

- `TecplotPltWriter.close()` and `TecplotDatWriter.close()` now flush
  buffered auxiliary data, matching `TecplotSzlWriter`'s existing behavior.
  Previously, calling `add_auxdataset_dict()`/`add_auxvar_dict()` after the
  first zone had already been written silently discarded that data on PLT
  and DAT output, no error, nothing written.
