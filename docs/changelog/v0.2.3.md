## [0.2.3]

Bug fixes and added utilities.

### Added

- Paraview plugin to read in all Tecplot file types
  - Fixes errors in packaged ParaView Tecplot for zone header fields `SOLUTIONTIME` and `STRANDID`.
  - Provdes `.szplt` file format reading capability in ParaView.
  - Automatically converts aux data to `vtkFieldData`.

### Fixed

- `dat.Read` did not have `zone_index` or `var_index` properties. Fixed to match `szl` and `plt` modules.
