## [0.3.3]

### Added

- Added option to automatically share grid when merging with `tecmerge`.
- Added package level functions to query Tecplot files for zone list, variable
  list, etc. without fully paring the file (quick and low memory).
- 3rd party plugins using `tecio` are now automatically added to the install
  `share` folder when installed with pip.
